# Structure

This document describes the directory organization and key file locations of the KLE Tech Chatbot project.

## Directory Layout
```text
/Chat_bot
├── chat.py             # Main entry point and Chatbot logic
├── generate_dataset.py # Step 1: Raw university knowledge source → kle_tech_dataset.jsonl
├── extract_facts.py    # Step 2: Extracts & normalizes unique facts → college_data.jsonl
├── embedder.py         # Step 3: Generates vector embeddings → embeddings.npy, facts.json
├── requirements.txt    # Project dependencies
├── README.md           # Documentation
├── .planning/          # GSD planning and codebase maps
│   └── codebase/       # Current codebase analysis docs
│
├── [DATA FILES]
├── kle_tech_dataset.jsonl # Raw conversational Q&A pairs (generated by step 1)
├── college_data.jsonl  # Normalized factual database (generated by step 2)
├── facts.json          # Fact text lookup index (generated by step 3)
├── embeddings.npy      # Vector database / SBERT embeddings (generated by step 3)
│
├── diagnostic_sim.py   # Utility for debugging retrieval similarity scores
└── .gitignore          # File exclusion rules
```

## Build Chain
```
generate_dataset.py  →  kle_tech_dataset.jsonl
     ↓
extract_facts.py     →  college_data.jsonl
     ↓
embedder.py          →  embeddings.npy + facts.json
     ↓
chat.py              (loads embeddings + facts at runtime)
```

## Key Modules
- **`chat.py`**: Contains `KLETechChatbot` class. Implements the Hybrid Filter, two-stage retrieval, Deterministic Bypass, and LLM interaction.
- **`generate_dataset.py`**: Defines all raw academic data (timetables, fees, placements, holidays) and writes `kle_tech_dataset.jsonl`.
- **`extract_facts.py`**: Reads `kle_tech_dataset.jsonl`, deduplicates assistant answers, normalizes Roman numerals (IV→Semester 4), appends supplementary facts, and writes `college_data.jsonl`.
- **`embedder.py`**: Uses `SentenceTransformer` (BAAI/bge-small-en-v1.5) to encode facts from `college_data.jsonl` and writes the vector index.
